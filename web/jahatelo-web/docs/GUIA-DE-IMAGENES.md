# Guía de imágenes de Jahatelo

| Uso | Tamaño mínimo | Proporción objetivo | Marca de agua |
|---|---:|---:|---:|
| Logo | 512×512 px | 1:1, con espacio seguro alrededor | No |
| Portada web | 1600×900 px | 16:9 | Sí |
| Portada app | 1200×1500 px | 4:5 | Sí |
| Miniatura | 800×600 px | 4:3 | Sí |
| Habitación | 1200×800 px | 3:2 | Sí |
| Promoción | 1080×1080 px | 1:1 | Sí |
| Banner | 1600×600 px | 8:3 | Sí |

## Reglas de carga

- Formatos admitidos: JPEG, PNG y WebP.
- Peso máximo del original: 4 MB.
- Las fotografías se rotan según EXIF, se convierten a WebP y se comprimen automáticamente.
- Las portadas y habitaciones generan una variante optimizada para la app.
- No colocar textos o logos importantes pegados a los bordes: conservar una zona segura del 10%.
- Antes de publicar, revisar los recortes web y app. Una imagen horizontal no debe reutilizarse como portada vertical sin verificar el encuadre.
